02 — AI Projects / Case Studies

Conceptual work & explorations

These are framed as Concept / Exploration rather than completed production work — each maps a real project-delivery problem to an AI-based approach.

Concept / Exploration

AI-Assisted Project Risk Analysis

Problem

Risk registers are often updated late and depend on whoever remembers to flag an issue.

AI Opportunity

Surface risk patterns earlier by reading status updates, meeting notes, and timelines together.

Proposed Workflow

An LLM reviews weekly status inputs, flags emerging risk language, and drafts a risk-register entry for PM review.

Tools / Architecture

LLM + lightweight RAG over prior project documentation for context.

Expected Business Value

Earlier risk visibility and less manual scanning of status reports.

Risks & Limitations

False positives if not tuned; still requires human judgment before escalation.

Concept / Exploration

AI Requirements Analysis

Problem

Raw stakeholder requirements are inconsistent in format and often ambiguous.

AI Opportunity

Convert unstructured requirement notes into structured, testable requirement statements.

Proposed Workflow

An LLM parses raw notes, groups related requirements, and flags gaps or contradictions for BA review.

Tools / Architecture

LLM with a structured-output prompt template; human-in-the-loop review step.

Expected Business Value

Faster first-draft requirement documentation and fewer missed edge cases.

Risks & Limitations

Cannot replace stakeholder validation; quality depends on the clarity of source notes.

Concept / Exploration

RAG-Based Project Knowledge Assistant

Problem

Project knowledge is scattered across documents, chats, and tickets, making it hard to answer "have we solved this before?"

AI Opportunity

A retrieval-grounded assistant that answers questions using the project's own documentation.

Proposed Workflow

Documents are embedded into a vector store; a chat interface retrieves relevant chunks and grounds the LLM's answer in them, with citations.

Tools / Architecture

Embeddings model, vector database, LLM, citation-aware prompt design.

Expected Business Value

Less time spent searching, faster onboarding for new team members.

Risks & Limitations

Answer quality depends on document hygiene; needs guardrails against outdated sources.

Concept / Exploration

AI Project Status Reporting

Problem

Compiling weekly status reports from Jira, emails, and meeting notes is repetitive manual work.

AI Opportunity

Auto-draft a status report from connected tools, leaving the PM to review and adjust tone/emphasis.

Proposed Workflow

Tool-calling agent pulls ticket status and recent updates, then drafts a structured report for PM sign-off.

Tools / Architecture

LLM + tool calling into Jira/Confluence-style APIs.

Expected Business Value

Time saved on reporting; more consistent report structure across projects.

Risks & Limitations

Requires access permissions and careful handling of sensitive project data.

Concept / Exploration

AI Meeting & Action-Item Assistant

Problem

Action items from meetings often get lost or aren't clearly assigned.

AI Opportunity

Extract decisions and action items from meeting transcripts automatically.

Proposed Workflow

An LLM summarizes the transcript, extracts action items with owners and due dates, and pushes them to a task tracker.

Tools / Architecture

Speech-to-text (if needed) + LLM summarization + tool calling into a task tracker.

Expected Business Value

Fewer dropped action items and less manual note-taking.

Risks & Limitations

Transcript quality affects accuracy; sensitive meetings need access controls.

Concept / Exploration

Agentic Workflow Automation

Problem

Multi-step admin workflows (intake → triage → assignment → follow-up) consume PM time.

AI Opportunity

Chain multiple specialized agents to handle a workflow end to end, with a human checkpoint before anything is finalized.

Proposed Workflow

An orchestrating agent routes work to task-specific sub-agents (triage, drafting, notification) and reports back for approval.

Tools / Architecture

Multi-agent orchestration, tool calling, shared memory/context between agents.

Expected Business Value

Reduced turnaround time on repeatable admin workflows.

Risks & Limitations

Requires strong guardrails; errors can compound across chained steps.
